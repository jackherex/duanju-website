常见问题

官网上的剧集点进去能直接播吗？
官网上的剧集只做展示，帮你了解有哪些内容。想真正播放，请下载手机版、电脑版或 TV 盒子版客户端，全部内容都在里面。
下载按钮为什么跳转到 GitHub？
我们的安装包统一放在 GitHub 的发布页里。点下载按钮会直接打开最新版本的发布页面， 你可以在那里看到版本号、更新说明和全部安装包，按需选择下载。 这样做的好处是：无论我们更新到哪一版，官网永远指向最新的那个，不会给你旧版本。
要收费吗？会有广告吗？
完全免费，不设 VIP，也没有贴片广告。App 内所有剧集都能直接观看。
WebDAV 同步要怎么设置？
在设置里找到「播放记录同步」，填入你的 WebDAV 地址、账号和密码即可。 支持群晖、坚果云、OpenList 等标准 WebDAV 服务，内网自建的 http 地址也支持。 不需要注册任何账号，记录直接存在你自己的盘里。
下载的弹幕在断网时还能看吗？
可以。批量下载时会把弹幕一起保存到本地，离线播放时照常显示，跟在线观看没有区别。
Android 装不上怎么办？
本应用未上架应用商店，安装时系统可能提示"未知来源"。请到系统设置里允许该来源安装即可。若提示解析失败，说明设备架构不匹配，请确认你的手机是 arm64 机型。
Windows 版怎么用？
下载 ZIP 后解压到任意目录，双击 duanjuzhijia2.exe 即可运行，免安装、绿色版。想放桌面的话，右键 exe 发送快捷方式到桌面。
手机和电脑能互相接着看吗？
配置好 WebDAV 同步后就行。手机上看到第 17 集的一半，电脑打开会从同一个位置继续。两端冲突时会自动保留最新的那个进度。
画质增强是每个平台都有吗？
目前只有 Windows 电脑版支持，手机版和 TV 版暂时没有。开启后会把实际输出分辨率往上推， 最高到 4K（3840 × 2160）。它依赖显卡实时逐帧计算，所以显卡偏弱、笔记本在用电池、 或者系统发烫时会自动退回原画 —— 宁可画面朴素，也不让播放卡顿。 另外播放器的画质增强是"锦上添花"，建议先在源站选高清画质再看。
TV 盒子版怎么找不到安装包？
TV 盒子版是独立维护的一条线，只在确实有更新时才发布安装包，所以最新版本的发布页上可能没有它。 可以点开全部版本列表 往回翻，找带 TV 包的历史版本。急着看的话，用手机版投屏到电视是更省事的选择。
